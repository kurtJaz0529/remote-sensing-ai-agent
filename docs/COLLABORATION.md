更新日期：2026-10-19。依据用户最新要求：GitHub 由本地 Codex 与 Antigravity 继续开发和上传文件；云端 Codex 已完成并在 Notion 交付核心包，后续可承接补充工作。

## 分支和所有权

从最新 main 为每个任务建立分支。公共接口变更先约定影响范围，提交给集成负责人审查；不允许两个客户端同时修改同一文件。已完成工作提交后再交接，不通过共享未提交文件猜测版本。

本地 Codex 与 Antigravity 可以在同一 GitHub 账号已授权的不同工作副本中工作。若使用不同账号，所有者在 **Settings → Collaborators → Add people** 邀请具体账号。公开访问仅提供读取、Fork、Issue 和 PR 入口，不自动授予所有人直接写权限。

## Antigravity 接手说明

在 Antigravity 中打开本仓库的独立工作副本，先读取 AGENTS.md、README、docs/HANDOFF.md、contracts/ 和当前任务。可将以下说明作为启动提示：

```text
你负责本仓库的知识、Skills、方法、核验和报告工作。
先检查 Git 状态与相关任务的最新 Notion 记录，避免重做云端已交付核心。
按依赖领取 T05/T06/T07，后续承接 T12、T17–T23 与 T29。
在自己的任务分支修改，按提交上传文件并发起 PR；不与本地 Codex 共写文件。
方法/核验器交本地 Codex 或另行指定的云端 Codex 复核，不能自签独立验收。
只上传可公开文件；原件、密钥、签名链接和保留答案留在本地。
每批次更新 Notion 原任务：产物/commit、验证、未验证项、问题与下一步。
```

上述只是接手说明，没有自动向其他聊天发消息，也没有启动外部 Agent。云端后续任务需明确输入、允许修改的文件、验收条件与证据范围。
