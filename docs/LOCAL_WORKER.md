# T08 持久 worker 与三软件最小验证

本页保留前一批次状态。最新接入已推进到固定原生后端，且用户指定只用MCP，默认入口改为 [MCP_ONLY](MCP_ONLY.md)；旧JSON-RPC入口仅作为历史协议测试，不作为新软件接入方式。

本批在协议 0.1.0 上新增 `orchestrator.local_worker`。协调器配置示例：

```json
{"command":["<本项目Python绝对路径>","-m","orchestrator.local_worker","--root","<runtime绝对路径>"],"timeout_seconds":30}
```

必须从已安装本项目的环境运行。JSON-RPC 使用既有 JsonWorker；stdout 只有响应，子进程日志写入对应 run 的 events/local-worker.log。任务先登记 local_jobs.sqlite 再启动独立进程；每个 runner 仅由 queued 状态领取一次。输入与确认在提交和实际执行前都复验。重复键相同载荷返回原结果，键冲突拒绝。

软件锁与项目锁记录 owner、PID、心跳。进程异常退出后保留状态和锁，不按年龄接管或自动重放；需人工核对 PID/输出并协调。软件忙时当前版本返回明确失败，不自动排队重试。未知 job 只报需协调，不创建新任务。

取消 queued 任务直接持久取消；running 任务先记录请求，只有 runner 检查并停止后才报告 cancelled。只操作本 worker 的任务，不终止用户其他进程。测试 handler 为可协作取消的 mock.echo；未注册任意命令、任意脚本或真实软件处理入口。原件保护依赖只读 handler 和重新验哈希，不宣称操作系统级沙箱。

## 实测边界

- 11 项新增 worker 测试覆盖独立子进程存续/恢复、重复提交、确认撤销、输入修改、排队/运行取消、锁冲突、超时、启动失败、未知任务、在途任务不重放。
- 本轮全套 66 项测试，无失败/错误；1 项 Windows 符号链接创建测试因权限跳过。
- MATLAB R2022a：基础 MATLAB 读取登记 uint8/BSQ 原件，16×16×6 子集计算六波段存储值均值，保存 MAT 并重读一致。固定格式适配器不冒充通用 ENVI 读取器，不依赖缺失的高光谱工具箱。MCP 成功不等于 Engine 回退路径已验证。
- ENVI 5.6 Task Engine：原生 SubsetRaster，SUB_RECT=[0,0,15,15]、BANDS=[0,1,2,3,4,5]；真实 DAT/HDR，独立逐字节核对与源子集相同。Classic GUI 仍需独立验证。
- ArcGIS Pro 3.6 专用 Python：原生 CopyRaster、全图数组相同，保存 aprx、重开无坏链，CRS 保持 Unknown；后台接口通过不等于 GUI 截图通过。

本批不是正式分类实验。最小探测经用户继续全部任务的指令授权，输出在全新本地目录；没有将这些直接探测伪装为统一编排运行。真实数据与工程留本地，只发布哈希、统计和源码。原件 SHA256 在执行前后保持一致。
