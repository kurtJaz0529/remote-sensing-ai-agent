# 本版决定
- 首先建设一套能复用的遥感 Agent 运行底座：知识库 + Skills + 方法库 + MCP 适配器 + 执行/证据/核验工作流。
- 本地 Codex负责用户电脑环境、三软件适配、本地执行与真实截图；云端 Codex负责核心编排、接口、检索、集成与交叉评审；Gemini（Antigravity）作为同一成员负责知识研究、方法库、Skills、核验组件、报告与教学链。
- 三成员属于开发协作。产品运行时由一个任务协调器管理计划、执行、核验和归档职能，不强制每一步调用多个模型。
- 首个验收案例使用用户已有分类实验；另外增加一个用户提供数据的基础处理/指数案例。三软件都需证明连接能力，但单个实验只调用必要软件。
- 先使用 Python 命令行、JSON Schema、SQLite、文件产物目录与 Git。检索先做关键词/结构化过滤，确有收益再加入向量检索；暂不引入大型分布式平台。
- 首发模型、软件版本、硬件与许可由环境发现任务实测，不从历史笔记推定为当前事实。
